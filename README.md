# Vespera – Event Management Website

## About the Project

Vespera is a modern, responsive event management and discovery platform based in Nepal. It helps users explore upcoming events, discover exciting experiences, view detailed event information, and register for their preferred events through a simple and user-friendly interface.

The website is designed to provide a smooth and engaging experience with modern UI design, interactive features, and responsive layouts.

## Features

- **Modern Homepage:** Attractive hero section with featured upcoming events.
- **Event Exploration:** Browse events from different categories.
- **Search Functionality:** Search events by name, venue, location, or category.
- **Category Filtering:** Filter events by Technology, Music, Cultural, Sports, Workshops, and Business.
- **Event Details:** View complete event information, date, time, venue, and description.
- **Event Registration:** Register for events using a simple registration form.
- **Form Validation:** JavaScript-based validation for user information.
- **Registration Confirmation:** Unique registration ID and confirmation message.
- **Local Storage:** Save and retrieve registration information.
- **Dark/Light Mode:** Switch between dark and light themes.
- **Event Countdown:** Countdown timer for upcoming events.
- **Responsive Design:** Compatible with mobile phones, tablets, and desktops.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, animations and responsive design.
- JavaScript – Interactive functionality and form validation.
- Local Storage – Client-side registration data management.
- Git & GitHub – Version control and project submission.
